# Shared UX System

## Shared information architecture
Home; Files; Search; Tools; Activity; Settings.

Settings contains General, Appearance, File Management, Privacy & Safety, Updates, Help & About.

Help & About contains About FileMind, Getting Started, User Guide, What's New, Troubleshooting, Diagnostics, Feedback, Credits, and Licenses.

## Shared operation lifecycle
Analyze -> Preview -> Confirm -> Execute -> Result -> Undo/View Activity.

Never perform a destructive operation merely because analysis completed. Clearly identify irreversible actions before confirmation.

## Shared statuses
Analyzing, Ready, Needs Review, Duplicate, Suggested, Protected, Excluded, Modified, New, Large File, AI Suggested, Completed, Failed, Cancelled.

## Empty states
Every empty state must explain what happened and offer the most useful next action. Avoid dead-end messages such as only “No files found.”

## Explainability
Smart recommendations should expose a “Why?” detail showing relevant signals and confidence. Low-confidence actions should default to Needs Review rather than automatic mutation.

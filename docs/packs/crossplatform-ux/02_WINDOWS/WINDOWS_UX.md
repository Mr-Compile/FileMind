# Windows UX Adaptation

- Use desktop navigation appropriate to the existing FileMind shell.
- Support Back, Forward, Parent Folder and clickable breadcrumbs.
- Preserve route state: scroll position, selection, search, filters, sorting and view mode when returning.
- Provide keyboard shortcuts and a searchable shortcut reference.
- Provide Ctrl+K command palette for navigation and common actions.
- Allow multi-selection and desktop-density file views.
- Task Center should support background/minimized operations without blocking normal browsing.
- Diagnostics may expose platform, architecture, app version/build and service health.
- About FileMind should feel like a native desktop settings/about surface, not a pasted README.

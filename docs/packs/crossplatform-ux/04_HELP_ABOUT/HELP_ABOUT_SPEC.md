# Help & About Specification

## About FileMind
Show logo, product name, tagline, version/build, short purpose statement, Getting Started, What's New, Documentation/User Guide, Report a Problem, Privacy, Licenses and Credits.

Preferred title: **About FileMind**, not “About Us”.

## Getting Started
Teach the real workflow: choose folder -> analyze -> review suggestions -> approve changes. Keep onboarding short and action-oriented.

## User Guide
Organize by user tasks rather than internal modules: browsing, search, organizing, duplicates, smart suggestions, activity/undo, privacy and settings.

## What's New
Show release highlights once after an update and retain them here for later access.

## Troubleshooting
Provide common problems, recovery actions and links into Diagnostics where useful.

## Diagnostics
Expose safe support information and health checks. Include Copy Diagnostic Information, but exclude private filenames/paths by default unless the user deliberately opts in.

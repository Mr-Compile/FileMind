# Cross-Platform UX QA

- About FileMind opens correctly on Windows and Android.
- Version/build information is accurate.
- Help pages have no dead-end navigation.
- Back behavior restores prior state.
- Windows back/forward/breadcrumbs behave consistently.
- Android system back behaves predictably.
- Destructive actions require explicit confirmation.
- Preview accurately represents the intended operation.
- Irreversible operations are labeled before execution.
- Undo works where advertised.
- Activity records completed/failed/cancelled operations appropriately.
- Task Center reflects active operations accurately.
- Low-confidence smart suggestions can be reviewed.
- Protected-folder behavior is enforced.
- Empty states provide a useful next action.
- Diagnostics avoid exposing private file information by default.
- Touch targets and keyboard navigation are usable on their respective platforms.
- Existing FileMind functionality remains intact after implementation.

# Navigation & Routing

## Routes
Define stable routes for Home, Files, Search, Tools, Activity, Settings and each Help & About destination.

## History behavior
Back/forward must return users to meaningful prior state, not merely reload a default page. Persist relevant query/filter/sort/view/selection/scroll state.

## Deep links
Design routes so Settings/About/Help destinations can be opened directly from contextual help, errors, update notices and diagnostics.

## Platform behavior
Windows may expose explicit back/forward controls and breadcrumbs. Android must integrate with system back semantics. Shared route identifiers should map to platform-specific presentations.

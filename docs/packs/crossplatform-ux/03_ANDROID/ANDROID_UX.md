# Android UX Adaptation

- Preserve the same FileMind concepts while using touch-first layouts and mobile navigation.
- Respect Android system back behavior and maintain navigation state.
- Use responsive cards/lists, adequate touch targets and concise action sheets/dialogs.
- Replace desktop-only shortcuts with discoverable touch actions; do not expose Ctrl+K as a primary mobile interaction.
- Long-running tasks should remain visible through the in-app Task Center and use platform-appropriate background behavior where supported by the architecture.
- Clearly explain storage/folder permissions and provide a direct Manage Access flow.
- About FileMind should use compact mobile sections while retaining version, help, What's New, privacy, credits and licenses.

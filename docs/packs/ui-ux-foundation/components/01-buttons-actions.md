# Buttons & Actions

Hierarchy:
- Primary: one dominant action per task region.
- Secondary: alternative safe action.
- Tertiary/text: low-emphasis action.
- Destructive: irreversible/high-risk action.
- Icon button: only when icon meaning is established; tooltip/accessible label required on desktop.

States: default, hover (desktop), pressed, focus, disabled, loading.

Do not label destructive actions vaguely as `OK`. Use explicit verbs such as `Delete 24 files`.

# File Lists & Tables

Windows may use table/list views with:
- name
- type
- size
- modified date
- location
- status
- selection

Support sorting, filtering, multi-select, keyboard selection, context menu, drag/drop where safe, breadcrumbs, and clear selected state.

Android should use touch-friendly rows/cards, selection mode, contextual top app bar, filters/sort sheets, and progressive disclosure.

File-type icons are supplementary; file name and metadata remain primary.

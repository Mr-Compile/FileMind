# Chips, Badges & Status

## Canonical operation states
- Ready
- Queued
- Checking
- Running
- Paused
- Completed
- Completed with warnings
- Failed
- Cancelled
- Offline
- Unsupported
- Permission required

## Representation
Each state gets:
1. semantic color
2. icon
3. human-readable label
4. optional short supporting text

Badges show compact counts or state. Chips may also be interactive filters; status chips must not accidentally look clickable unless they are.

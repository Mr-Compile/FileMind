# Windows UI Specification

## Style
Fluent-inspired Minimal Utility UI.

## Shell
- Title bar integration where framework permits
- Left navigation rail/sidebar
- Main content area
- Optional details/inspector pane on wide screens
- Operation center accessible globally
- Command/search experience

## Desktop interactions
- Keyboard shortcuts
- Context menus
- Hover states/tooltips
- Multi-select
- Drag/drop
- Right-click actions
- Breadcrumbs
- Back/forward/up navigation
- Resizable layout
- Compact density option for file-heavy screens

## Visual treatment
Bento on Dashboard; opaque readable surfaces for data-heavy screens; restrained acrylic/glass for transient layers/navigation. Support light/dark/system.

# Android UI Specification

## Style
Material 3 Minimal Utility UI.

## Shell
Use adaptive navigation:
- phone: bottom navigation for primary destinations
- wider screens: navigation rail/pane when appropriate

## Mobile interactions
- large touch targets
- long-press selection where expected
- contextual selection app bar
- bottom sheets for contextual choices
- pull/explicit refresh only where meaningful
- system Back integration
- permission flows that explain why access is needed before requesting it

## Layout
Single-column first. Use adaptive two-pane layouts on larger devices where useful. Bento dashboard cards collapse cleanly.

Support Material-compatible light/dark/system themes while retaining File Organizer semantic tokens.

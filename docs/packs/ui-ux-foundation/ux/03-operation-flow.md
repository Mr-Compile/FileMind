# Standard Operation Flow

`Select source → Choose action → Pre-check → Resolve restrictions → Confirm if risky → Execute → Progress → Result → Next action`

## Pre-check
Validate before work begins:
- source still exists
- destination is valid
- storage is sufficient
- required permission exists
- operation is supported
- conflicts are understood
- device remains available

## Result
Summarize outcomes in user language:
- completed count
- skipped count
- warnings
- failures
- where files went
- undo/retry/open-location when supported

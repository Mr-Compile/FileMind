# Information Architecture

Primary product areas:
- Dashboard
- Files
- Organizer
- Tools
- Search
- Devices
- Activity
- Settings

Do not expose every capability as top-level navigation. Group secondary utilities inside Tools and contextual actions.

Settings:
- General
- Appearance
- File behavior
- Permissions
- Notifications
- Advanced
- About

Advanced settings must not become a dumping ground for required normal-user controls.

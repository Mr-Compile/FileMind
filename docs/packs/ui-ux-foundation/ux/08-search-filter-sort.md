# Search, Filter & Sort

Search should be prominent and forgiving.

Capabilities:
- file/folder name
- type/category
- location/scope
- size range
- modified date
- status where relevant

Show active filters as removable chips. Provide `Clear all` when multiple filters are active.

No-result state should distinguish:
- nothing matches the query
- nothing exists in the selected scope
- location is unavailable

Windows supports keyboard focus shortcut and richer filter panels. Android uses compact filter/sort sheets.

# Typography & Fonts

Prefer system-native fonts for performance, familiarity, localization, and platform consistency.

## Windows
Primary: **Segoe UI Variable / Segoe UI** with system fallback.

## Android
Primary: **Roboto / Roboto Flex** with system fallback.

## Optional brand typography
A bundled brand font may be introduced only for logo/marketing surfaces. It must not replace system fonts for file lists, settings, errors, or operational UI unless licensing, rendering, localization, and accessibility are verified.

## Scale
- Display: rare; hero/empty-state only
- H1: page title
- H2: section title
- H3: card/group title
- Body: primary content
- Body small: supporting metadata
- Label: controls/chips
- Mono: technical identifiers only when the user explicitly asks to see technical details

Use readable line height and never communicate importance through font size alone.

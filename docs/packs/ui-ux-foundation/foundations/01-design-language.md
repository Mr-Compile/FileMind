# Design Language

## Chosen visual system

### Windows
Use **Fluent-inspired Minimalism** as the core. Use Bento-style cards for dashboard summaries and restrained translucent/acrylic surfaces for navigation, command/search overlays, dialogs, and temporary layers.

### Android
Use **Material Design 3** behavior and component conventions with the same product tokens and semantic language. Bento arrangements may be used where screen width permits, but must collapse naturally on phones.

### Shared character
- Clean, modern utility aesthetic
- Medium corner radius rather than excessively rounded controls
- Strong information hierarchy
- Calm neutral surfaces with semantic color accents
- Minimal decorative effects
- Clear icon + text combinations
- Dense information only where the platform supports it
- Motion communicates state; it is never decoration-only

## Do not use
- Glass on every card
- Neumorphic controls
- Cyberpunk/neon styling
- Raw console/error presentation
- Excessive gradients
- Hidden destructive actions
- Color-only statuses
- Tiny icon-only controls for important actions

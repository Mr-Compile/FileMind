# Light, Dark & System Themes

Support:
1. System/default
2. Light
3. Dark

Theme changes must not alter semantic meaning.

## Light
Bright neutral background, opaque content surfaces, subtle borders, restrained shadows.

## Dark
Dark neutral background—not pure black by default—slightly elevated cards, high-contrast readable text, softened semantic colors that still meet contrast requirements.

## Rules
- Persist the user's theme choice.
- Respect OS theme when set to System.
- Re-check icons, illustrations, SVGs, dividers, charts, disabled states, hover/focus, selections, and semantic colors in both themes.
- Avoid pure white-on-black everywhere.
- Glass/transparency must remain legible over every allowed background.

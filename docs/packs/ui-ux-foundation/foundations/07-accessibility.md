# Accessibility

- WCAG-minded contrast for text and interactive states.
- Keyboard support on Windows.
- Visible focus indicators.
- Screen-reader labels for actionable icons.
- Logical focus order.
- Touch targets appropriate for Android.
- Do not use color alone for state.
- Support text scaling without clipping critical actions.
- Reduced motion support.
- Error messages identify the field/problem and a recovery action.
- Dialog focus is trapped appropriately and returned to the invoking control when closed.
- Progress changes should be exposed to assistive technologies without excessive announcements.

# Motion & Feedback

Motion explains what changed.

Use:
- subtle hover/press response
- page/content transitions
- progress animations
- expand/collapse
- success completion
- drag/drop target feedback

Avoid long or ornamental animation during file operations.

Respect reduced-motion OS settings. A reduced-motion experience must remain fully understandable.

Recommended durations:
- micro interaction: ~100–160ms
- component transition: ~160–240ms
- page/layer transition: ~200–300ms

Never delay a real operation merely to complete an animation.

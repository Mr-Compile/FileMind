# Phase 9 — Cross-Platform Profiles

Define a versioned `organizer-profile.json` schema containing rules, collections, categories, subjects, projects, aliases, naming templates, exclusions, and portable preferences. Separate platform-only settings such as Windows paths and Android URI grants.

Support export, validation, preview, import, migration, backup, and restore. Initial cross-device transfer is profile data only—not user files. Future cloud sync must resolve conflicts explicitly and preserve local safety settings.

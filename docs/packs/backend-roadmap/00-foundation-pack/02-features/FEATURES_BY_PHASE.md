# Features by Phase

## P1 Core Foundation
Folder scan, recursive scan, type/MIME detection, filename analysis, basic classification, custom destinations, folder creation, move/copy/rename, SQLite index, history, undo, conflicts, protected paths, exclusions, dry run, preview.

## P2 Smart Organization
Collections, categories/subcategories, subject codes/names/aliases/keywords, project aliases/keywords, school document types, context routing, confidence, Smart Inbox, Manual/Smart/Automatic modes.

## P3 Rule Engine
Visual-rule backend model, JSON rules, conditions/actions, priorities, validation, conflicts, test/preview, import/export, templates.

## P4 Windows Automation
Watch folders, stable-file/download completion checks, event queue/debounce, startup/background operation, tray/notifications backend, external drives, Explorer action contracts.

## P5 File Intelligence
PDF/DOCX/PPTX/TXT extraction, metadata/EXIF/audio/video analysis, content classification, screenshot/media recognition, smart rename and templates.

## P6 Duplicates & Storage
Size prefilter, partial/full hashing, duplicate groups, similar/version candidates, large/old file analysis, storage breakdown and savings estimates.

## P7 Groq AI
Optional AI provider, ambiguous classification, context/subject/project analysis, destination/category/collection/rename suggestions, explanations, natural-language rule generation/search interpretation, privacy controls, limits, fallback.

## P8 Android
SAF/MediaStore scanning and actions, authorized folders, WorkManager scheduling, notifications, share-target contracts, history/undo where supported, shared rule/profile formats, optional Groq.

## P9 Search
SQLite FTS5, filename/metadata/content/subject/project/collection search, filters, natural-language query interpretation, later semantic index.

## P10 Cross-Platform
Profile import/export/backup/restore; shared rules, collections, subjects, projects, aliases, naming templates; later account/profile sync. Do not make file sync a core responsibility.

## P11 Advanced
Local AI, semantic index, correction learning, rule/collection suggestions, related/version intelligence, adaptive confidence, multiple AI providers.

# Phase Checklist

For every phase:
- [ ] Contracts documented and versioned where external/persisted.
- [ ] Happy path implemented.
- [ ] Validation and structured errors implemented.
- [ ] Cancellation/retry semantics defined where asynchronous.
- [ ] Persistence/migrations updated safely.
- [ ] Security/privacy impact reviewed.
- [ ] Undo/rollback impact reviewed for mutations.
- [ ] Unit tests added.
- [ ] Integration/fixture tests added where applicable.
- [ ] Logs/telemetry are privacy-safe and useful.
- [ ] README/architecture docs updated.
- [ ] No UI dependency introduced into domain/core.
- [ ] No AI/provider dependency introduced into filesystem execution.

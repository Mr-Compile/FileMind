# Definition of Done

A backend feature is done when:
- Contract/domain behavior is defined.
- Success and failure paths are implemented.
- Permissions/safety are checked.
- Errors are typed/actionable.
- Operation is logged where relevant.
- Undo/recovery behavior is explicitly defined.
- Unit tests cover core rules.
- Integration tests cover adapter/repository boundaries.
- Offline behavior is tested.
- AI failure does not break local organization.
- No direct filesystem mutation exists outside approved platform action adapters.

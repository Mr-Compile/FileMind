# Implementation Plan

## Foundation Sprint
Freeze contracts, module boundaries, JSON schema versions, safety policies, operation transaction model, error taxonomy, test fixtures, and coding rules.

## P1-P4 = Windows V1
Deliver a usable offline Windows organizer before expanding platforms. Exit criteria: reliable scan/classify/rule/preview/execute/history/undo/watch-folder flow with automated tests and crash-safe transaction records.

## P5-P7 = Intelligence V2
Add extractors, metadata, rename, duplicates/storage, then Groq as optional fallback. AI must not be required for core acceptance tests.

## P8 = Android V1
Implement Android adapter and native client against stable shared contracts. Respect SAF/MediaStore limitations rather than imitating Windows paths.

## P9-P10 = Discovery + Portability
Search/indexing, profile portability, then optional sync.

## P11 = Advanced
Only after telemetry/user testing proves value: semantic/local AI, personalization, multi-provider.

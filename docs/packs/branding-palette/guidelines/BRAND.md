# FileMind Brand Rules
FileMind should feel modern, intelligent, clean, dependable and cross-platform.

Use Blue as the dominant brand/action color, Indigo as supporting emphasis, and Violet primarily for smart/intelligent functionality. Keep application surfaces neutral.

Do not use gradients for semantic errors/warnings/success. Never communicate state by color alone.

Splash screens should be simple and fast. Only display determinate progress when it represents real initialization progress.

Support System, Light and Dark themes. Brand identity stays recognizable in both.

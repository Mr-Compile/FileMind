# Modules

Inventory verified modules/components, their responsibilities, dependencies, and ownership boundaries. Do not create an inventory from assumptions.

| Module | Responsibility | Dependencies | Verified |
|---|---|---|---|
| `FileMind.Branding` | Platform-neutral brand color tokens (`BrandTokens`) + `ThemeMode`/`ThemePalette` resolution. Mirrors `branding/colors.json`; parity enforced by `FileMind.Branding.Tests`. | None (net10.0, no packages, no OS/UI APIs) | 2026-10-24 |
| `mockup/` | Dependency-free static HTML/CSS/JS interactive mockup of the approved UI — spec screens, organizer pipeline demo, console host simulator, architecture view. Links `branding/colors.css` directly so tokens can't drift. Sync rule: `docs/rules/MOCKUP_RULES.md`. | None (browser only; links `branding/colors.css`) | 2026-10-24 |
| `FileMind.Application/Duplicates` | `DuplicateDetectionService` (size→partial→full hash gating over `IFileIndexRepository`, stale-row invalidation, advisory similarity candidates) + `StorageAnalysisService` (kind/age buckets, largest/oldest, reclaimable estimate) + `DuplicatePlanBuilder` (review-first quarantine `ActionPlan`, KeepBoth, undo recipes). No delete path. | `IFileIndexRepository`, `IHashService`, `IFileSystemAdapter`, Domain contracts | 2026-10-24 |
| `FileMind.Application/Search` | `SearchUseCase` — FTS5 full-text (`ISearchIndex`) + structured filters (name/ext/kind/age) over `IFileIndexRepository`. Local-only retrieval. | `ISearchIndex`, `IFileIndexRepository` | 2026-10-24 |
| `file_content_index` (schema v3) | FTS5 virtual table (`unicode61`; `path`, `display_name`, `collection`, `subject`, `project`, `kind`, `content`). Populated by `FileIndexingService` when an `ISearchIndex` is wired; row deleted when the `file_index` row is removed. `ISearchIndex` impl lives on `SqliteStore`. | `e_sqlite3` FTS5 | 2026-10-24 |
| `FileMind.Intelligence.AI` | Optional Groq integration (PLAN-009/020): `AiPrivacyGate` (per-field consent via `AiConsent`, protected paths never sent), `GroqChatClient` (bounded timeouts, retry honoring `retry-after`, 429 breaker, auth-fail detection, `x-ratelimit-*` sink), `GroqProvider` `IAIProvider` (cache → `AiQuotaGate` pre-flight → transport → shape validation), `AiAdvisor` `IAiAdvisor` (mode-gated low-confidence escalation, capped `ai-signal` evidence), `AiSuggestionCache`, `AiQuotaGate`/`AiQuotaPolicy` (daily+weekly+minute budgets, provider-header reconciliation), `AiRuleDrafter`/`AiQueryInterpreter`, `DotEnv`/`EnvSecretStore`. Advisory only. | `IAIProvider`/`IAiPrivacyGate`/`IAiAdvisor`/`ISecretStore`/`IAiUsageLedger`/`IAiAuditRepository` ports, `IProtectedPathProvider`, `HttpClient` | 2026-10-24 |
| `ai_usage` (schema v4) | AI usage ledger (`at`, `request_hash`, `model`, `purpose`, `prompt_tokens`, `completion_tokens`, `outcome`). Written by `GroqChatClient` per call; read by `AiQuotaGate` rolling windows + `ai-usage` verb. Metadata only — never payload contents. | `SqliteStore` implements `IAiUsageLedger` | 2026-10-24 |
| `WindowsSecretStore` | DPAPI (`CryptProtectData`, CurrentUser) secret store under `%LOCALAPPDATA%\FileMind\secrets`; `filemind ai-key` verbs. | `ISecretStore`, crypt32 | 2026-10-24 |
| `android/core` | Pure-JVM Kotlin port of the domain engine + app pipeline: contracts (versioned `schemaVersion`, `@Serializable` for persisted payloads), normalization/matchers/confidence, rule engine + validator, safety engine, action planner/transaction/undo/rollback, scanner/decision/mode/pipeline. JUnit parity suite reads the shared `tests/fixtures/manifest.json`. | Kotlin 2.2.10, coroutines 1.10.2, kotlinx-serialization 1.9.0 — no Android APIs | 2026-10-24 |
| `android/platform` | `com.android.library` backend: `AndroidFileSystemAdapter` (SAF `DocumentFile`/`DocumentsContract` + MediaStore + `file://` sandbox), `UriGrantStore` (persisted grants + OS reconciliation), `AndroidCapabilityModel`/`GrantCoverage`/`SafPathNormalizer`/`AndroidProtectedPathProvider`, Room `FileMindDatabase` v2 + all repository impls, `ScanWorker`/`OrganizeWorker`/`FileMindWorkScheduler`, `NotificationContracts`/`AndroidNotificationService`, headless `ShareIntakeActivity`/`ShareIntake`, `FileMindAndroid` service graph. | `android/core`, AGP 9.0.1, Room 2.8.5, WorkManager 2.12.0, DocumentFile 1.1.0, core-ktx 1.17.0 | 2026-10-24 |
| `FileMindDatabase` (schema v2) | Room mirror of `SqliteStore` ports: rules, collections, subjects, projects, file_index, operations, smart_inbox, exclusions, protected_paths, watched_folders, settings, jobs, uri_grants, ai_audit (+ `ai_usage` via `MIGRATION_1_2`). Schema JSON exported to `android/platform/schemas/`. | Room 2.8.5 | 2026-10-24 |

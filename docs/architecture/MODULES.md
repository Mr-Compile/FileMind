# Modules

Inventory verified modules/components, their responsibilities, dependencies, and ownership boundaries. Do not create an inventory from assumptions.

|---|---|---|---|

| `FileMind.Intelligence.AI` | Optional Groq integration (PLAN-009/020): `AiPrivacyGate` (per-field consent via `AiConsent`, protected paths never sent), `GroqChatClient` (bounded timeouts, retry honoring `retry-after`, 429 breaker, auth-fail detection, `x-ratelimit-*` sink), `GroqProvider` `IAIProvider` (cache → `AiQuotaGate` pre-flight → transport → shape validation), `AiAdvisor` `IAiAdvisor` (mode-gated low-confidence escalation, capped `ai-signal` evidence), `AiSuggestionCache`, `AiQuotaGate`/`AiQuotaPolicy` (daily+weekly+minute budgets, provider-header reconciliation), `AiRuleDrafter`/`AiQueryInterpreter`, `DotEnv`/`EnvSecretStore`. | `ai_usage` (schema v4) | AI usage ledger (`at`, `request_hash`, `model`, `purpose`, `prompt_tokens`, `completion_tokens`, `outcome`). Written by `GroqChatClient` per call; read by `AiQuotaGate` rolling windows + `ai-usage` verb. Metadata only — never payload contents. | `SqliteStore` implements `IAiUsageLedger` | 2026-10-24 |
| `WindowsSecretStore` | DPAPI (`CryptProtectData`, CurrentUser) secret store under `%LOCALAPPDATA%\FileMind\secrets`; `filemind ai-key` verbs. | `ISecretStore`, crypt32 | 2026-10-24 |

Zero user-file mutation — all mutations via pipeline. UI/theme tokens merge `Themes/FmTheme.xaml` (canonical palette both modes) + `Themes/FmTypography.xaml`. | `FileMind.Application`/`Domain`/`Branding`, `FileMind.Infrastructure.Sqlite`, `FileMind.Platform.Windows`, `FileMind.Intelligence.Local`/`AI`, Windows App SDK 1.8 | 2026-10-24 |

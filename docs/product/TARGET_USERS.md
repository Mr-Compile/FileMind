# Target Users

Approved intent: users with structured collections who need deterministic,
undoable organization across Android and Windows. FileMind is
general-purpose — the personas below are ranked use cases, not an
exclusive audience.

## Primary

- **Students** — course files accumulate fast (lectures, assignments,
  downloads). Filenames frequently carry subject/course codes
  (`IT-412`, `cs301`, `MATH 201`), which FileMind treats as first-class
  routing signals into per-subject folders. An important use case — but
  not the only one.

- **Heavy downloaders / messy storage** — large Downloads folders where
  files never get sorted. Type-kind organization (`Files/Document`,
  `Files/Image`, …) delivers value with zero configuration.

## Secondary

- **Developers / programmers** — project folders, code archives, docs.
  Project matching + code-kind classification + rules for custom routing.

- **Office workers / professionals** — reports, presentations, contracts.
  Project/client matching routes work files per engagement.

- **Content creators** — mixed media (video, audio, images) benefits from
  kind + metadata classification (EXIF, ID3, MP4 tags).

## Shared Constraints

- Wants automatic organization but **retains control** (preview, dry-run,
  confirm, undo).
- Values **privacy/offline**: files are local; no uploads for core work.
- Uses **both platforms** or expects consistent concepts between
  Android and Windows.
- Storage is fragmented: removable drives (Windows), scoped storage +
  per-folder grants (Android).

# Purpose

FileMind exists to reduce file organization from manual labor to a
review-and-approve step.

**Problem it solves:** files accumulate unmanaged across Downloads,
Documents, and media folders. Organizing them by hand is tedious and
inconsistent; cloud organizers trade privacy for convenience.

**Value it provides:** a local, deterministic, explainable pipeline —
`Scan → Understand → Classify → Create Structure → Organize → Verify` —
that builds meaningful folder structures (subjects, kinds, projects) from
the signals already in the user's files, moves them safely under platform
permissions, and keeps every change reversible through undo recipes and
operation history.

**Identity:** FileMind is a smart automatic file *organization* system —
not a file manager, not a cleaner, not a cloud drive. It works offline
end-to-end; optional AI may advise but never executes filesystem actions.
